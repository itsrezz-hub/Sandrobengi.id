# SanrobengiTrip - Premium Landing Page

Landing page promosi Open Trip Pulau Sanrobengi[cite: 3].
Dibuat sesuai spesifikasi Project Brief menggunakan HTML5, CSS3, dan Vanilla JavaScript[cite: 3].

## Fitur Utama
- **Framework & Libraries**: Tailwind CSS, GSAP, AOS, SwiperJS, Fancybox, Lucide Icons[cite: 3].
- **SEO Ready**: Meta Open Graph, Schema.org JSON-LD, robots.txt, sitemap.xml[cite: 3].
- **Deployment**: Siap langsung di-deploy ke Netlify[cite: 3].

## Panduan Deploy ke Netlify
1. Hubungkan repository GitHub ini ke akun Netlify[cite: 3].
2. Atur **Publish directory** ke titik awal root (`/`).
3. Tekan **Deploy site**[cite: 3].
